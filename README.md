# Social Conclave — Interactive UI Design Prototype

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An interactive single-page web user interface prototype crafted for the **Social Conclave** collegiate event, showcasing responsive layout structuring, flexbox grids, and event agenda presentation.

## Usage
Simply clone the repository and open `index.html` in any modern web browser:
```bash
git clone https://github.com/4aru5h/social-conclave-design-prototype.git
open index.html
```
